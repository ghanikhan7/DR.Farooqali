SUDHA CLINIC WEBSITE & ADMIN PORTAL — SETUP GUIDE
Dr. Syed Farooq Ali — Sudha Clinic, Talab Katta, Hyderabad

See `README.md` for the complete step-by-step guide covering:
1. Enabling Firebase Email/Password Authentication in project `drfarooqali`
2. Creating the administrator account manually in Firebase Console
3. Copying your Admin User UID into `.env` (`VITE_FIREBASE_ADMIN_UID`) and `firestore.rules`
4. Publishing `firestore.rules` in Firebase Console -> Firestore Database -> Rules
5. Logging into `/admin` (`/admin/login`), resetting passwords (`/admin/forgot-password`),
   managing appointments (`/admin`), updating consultation fee & clinic settings (`/admin/settings`),
   and changing admin password/email (`/admin/profile`).
